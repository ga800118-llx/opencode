# Guai Code Beta Windows 内部试用说明

## 版本与范围

- 版本：`0.1.0-alpha.8`
- 目标测试系统：Windows 11 x64（64 位 Intel/AMD 电脑）
- 自动化验证环境：GitHub Windows Server 2025 x64；Windows 11 实机安装和界面验证仍待完成
- 定位：少量可信测试者使用的内部 Alpha，不是正式发布版本
- 当前安装器没有代码签名，可能触发 SmartScreen；是否出现提示及可用操作取决于文件信誉、下载来源和系统或组织策略
- 当前不提供自动更新；收到新版本时需要重新下载安装包

测试者不需要准备开发环境，也不需要另外安装 Bun、Node.js 或 Git。Guai Code Beta 已包含运行所需的 Git for Windows 组件，安装过程不会修改系统 `PATH` 或现有 Git 配置。

## 选择下载文件

优先使用单文件安装器：

```text
Guai-Code-Beta-0.1.0-alpha.8-win-x64.exe
```

安装器按当前 Windows 用户安装，不要求管理员权限。便携 ZIP 是安装器无法使用时的备用方案：

```text
Guai-Code-Beta-0.1.0-alpha.8-win-x64-portable.zip
```

使用 ZIP 时，应把整个压缩包解压到独立目录，再运行其中的 `Guai Code Beta.exe`；不要只取出 EXE。便携版仍会把个人配置和任务数据写入用户数据目录，并不是完全无痕模式。

## 校验下载文件

只使用直接从项目维护者处收到的交付目录，并在运行前核对 SHA-256。打开 PowerShell，进入下载目录：

```powershell
Set-Location "C:\Users\你的用户名\Downloads\Guai-Code-Beta-Windows"
Get-FileHash -Algorithm SHA256 -LiteralPath ".\Guai-Code-Beta-0.1.0-alpha.8-win-x64.exe"
Get-FileHash -Algorithm SHA256 -LiteralPath ".\Guai-Code-Beta-0.1.0-alpha.8-win-x64-portable.zip"
Get-Content -LiteralPath ".\SHA256SUMS.txt"
```

`Get-FileHash` 输出的 `Hash` 应与 `SHA256SUMS.txt` 中同名文件的值一致；十六进制字母大小写不影响哈希值，可忽略大小写比较。哈希值不一致、清单缺失或文件名异常时不要运行程序，请重新向维护者获取交付文件。

## 安装与 SmartScreen

1. 双击 `Guai-Code-Beta-0.1.0-alpha.8-win-x64.exe`。这是单文件、一键、按用户安装器。
2. 如果 SmartScreen 出现“Windows 已保护你的电脑”，先确认文件来源和 SHA-256 已通过校验。
3. 如果“更多信息”（`More info`）可用，点击后确认应用名称为 Guai Code Beta。
4. 确认无误后，如果“仍要运行”（`Run anyway`）可用，可选择“仍要运行”；如果任一选项不可用，或文件来源、应用名称、SHA-256 有任何疑问，停止安装并联系维护者。
5. 安装获准并完成后，从开始菜单打开 Guai Code Beta。

受管理设备的组织策略可能不提供“仍要运行”选项。不要绕过组织安全策略，也不要对来源不明或校验不一致的文件放行。SmartScreen 是否出现及其可用操作不代表正式发布状态。

## 首次模型配置

安装包不包含维护者的模型账号、API Key、项目或历史任务。首次打开后：

1. 打开“设置 → 模型”。
2. 添加自己的云模型、OpenAI 兼容私有模型、Ollama 或 LM Studio。
3. 填写自己的服务地址和 API Key，发现或手动添加模型。
4. 测试模型能力，保存配置，并选择一个模型作为默认模型。
5. 新建任务，先用不含敏感信息的简单问题确认回复正常。

API Key 仅应由密钥持有人输入。不要多人共用长期密钥；测试结束后可在模型服务商后台撤销专用于本次测试的密钥。

## 建议试用工作流

- 新建或打开一个不含机密的小型代码项目，确认文件浏览、搜索和修改正常。
- 在“受限”权限模式下执行命令，确认应用会在需要时请求批准。
- 切换“标准”和“自动批准”，确认权限模式符合界面选择。
- 完成一次包含读取文件、修改文件和查看差异的任务。
- 退出并重新打开应用，确认模型选择、项目、任务历史和权限模式符合预期。
- 验证内置 Git 可完成应用内需要的版本控制操作；系统无需另行配置 Git。
- 如使用私有接口或本地模型，分别验证正确配置和故意错误配置的提示。

模型的工具调用能力取决于模型和兼容接口实现。普通对话可用，不等于文件工具或命令工具一定可用。

## 反馈要求

反馈请包含：

- Windows 版本（在“设置 → 系统 → 系统信息”中查看）和 CPU 架构。
- 使用的是安装器还是便携 ZIP。
- 使用的模型名称、接口类型，以及是否为云端、私有或本地服务。
- 从启动到问题出现的完整操作步骤、预期结果和实际结果。
- 错误提示截图；截图前遮住账号、服务地址中的敏感参数和项目机密。
- 必要时使用应用内“导出调试日志”，发送前先检查日志内容。

反馈、截图和日志中不得包含 API Key、访问令牌、密码、Cookie、私有请求头或其他凭据。发现凭据意外暴露时，应先在服务商后台撤销凭据，再发送已清理的材料。

## 卸载与数据目录

安装版卸载步骤：

1. 完全退出 Guai Code Beta。
2. 打开“设置 → 应用 → 已安装的应用”。
3. 找到 Guai Code Beta，打开右侧菜单并选择“卸载”。

便携版退出应用后可直接删除解压目录。无论使用安装版还是便携版，卸载或删除程序目录都不会删除你的代码项目，也可能保留应用数据。Beta 的主要用户数据目录是：

```text
%APPDATA%\com.guaicode.desktop.beta
```

其中可能包含设置、模型 Profile、任务状态和日志。需要彻底重置时，先退出应用并备份仍需保留的内容，再删除该目录。项目源文件位于你自己选择的项目目录中，应单独管理；卸载程序不会替你删除项目。

- 当前没有代码签名，可能触发 SmartScreen；提示和可用操作取决于文件信誉、下载来源和系统或组织策略。仅使用来源可信且 SHA-256 一致的内部交付文件。

- 便携 ZIP 只是安装器的备用交付形式，不会把用户数据限制在解压目录内。
