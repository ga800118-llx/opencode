# Guai Code Beta 内部试用说明

## 版本范围

- 版本：`{{VERSION}}`
- 系统：Apple 芯片 Mac（M1、M2、M3、M4 及后续 Apple Silicon）
- 定位：少量可信朋友使用的内部测试版
- 当前没有 Apple Developer ID 签名与 Apple 公证
- 自动更新已关闭，后续版本需要重新下载安装

## 安装

1. 下载 DMG 和 `SHA256SUMS.txt`，放在同一个目录。
2. 在终端进入该目录，运行 `shasum -a 256 -c SHA256SUMS.txt --ignore-missing`。
3. 双击 DMG，把 `Guai Code Beta` 拖入“应用程序”。
4. 第一次打开时，macOS 会提示无法验证开发者。打开“系统设置 → 隐私与安全性”，找到 Guai Code Beta，选择“仍要打开”。
5. 只对直接从开发者处收到且校验值一致的安装包执行上述放行操作。

如果 DMG 无法使用，可以解压 ZIP，把 `Guai Code Beta.app` 移入“应用程序”，再按相同方式放行。

## 安装包来源

- `BUILD-INFO.json` 记录构建所用的完整 Git commit 和 tree 标识；源码从该提交导出到隔离目录后编译。
- 同一文件还记录模型目录快照、完整 Electron 运行时（包括权限位）、Bun 构建工具和内置 Git 的版本与 SHA-256，构建期间输入发生变化会终止打包。
- `trackedClean: true` 表示打包前后均没有 staged 或 unstaged 的 tracked 文件改动；否则打包脚本会拒绝产出交付目录。
- `untrackedFilesPresent` 只说明构建工作区是否存在未跟踪文件，不记录这些文件的名称或路径，也不把它们误报为 tracked 源码改动。
- `SHA256SUMS.txt` 同时覆盖 DMG、ZIP、`BUILD-INFO.json`、试用说明和许可证，可用于检查交付文件是否被修改。
- 应用已内置固定版本的 Git，不要求试用者另外安装 Git、Bun 或项目依赖。

这些信息用于内部版本追溯，不等同于 Apple Developer ID 签名或 Apple 公证。

## 首次配置

1. 打开“设置 → 模型”。
2. 添加自己的云模型、OpenAI 兼容私有模型、Ollama 或 LM Studio。
3. 输入自己的 API Key，发现模型并保存。
4. 选择一个模型设为默认，然后新建任务测试对话。

安装包不包含开发者的 API Key、模型账号、项目或历史任务。不要把 API Key 发在反馈截图或日志中，也不要多人共用同一个长期密钥。

## 建议验证

- 错误地址和错误 API Key 能显示明确错误。
- 正确配置可以发现模型并完成回复。
- “受限”模式执行命令前会询问权限。
- “标准”和“自动批准”可以切换。
- 退出并重新打开后，模型、项目、任务历史和权限模式仍保留。
- “简洁/高级”切换、运行位置和耗时折叠正常。

## 已知限制

- 仅提供 Apple Silicon 版本，不能在 Intel Mac 或 Windows 上安装。
- 未经过 Apple 公证，首次打开需要手动允许。
- 这是内部 Alpha，不承诺自动升级或数据格式长期不变。
- 模型是否支持工具调用取决于模型和兼容接口实现；普通对话可用不代表工具调用一定可用。
- 远程服务器必须使用支持当前权限模式接口的 Guai Code 版本。

## 反馈内容

出现问题时请提供：

- macOS 版本与 Mac 芯片型号。
- 使用的模型名称和接口类型，不要提供 API Key。
- 从启动到出现问题的操作步骤。
- 错误提示截图。
- 必要时使用应用内“导出调试日志”，发送前先检查其中没有自己的敏感信息。
