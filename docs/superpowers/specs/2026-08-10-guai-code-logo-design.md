# Guai Code Desktop App Logo Design

## Goal

Create a distinctive desktop application icon for Guai Code, an open-source AI coding agent. The icon must remain recognizable at 16–32 px and work across macOS, Windows, and Linux.

## Approved Direction

Use a letter-mark design centered on a bold geometric **G**. Tilt the G slightly counterclockwise to make the mark feel active and unconventional. Add one small square “anomaly pixel” near its upper-right edge to express AI inspiration, code mutation, and the playful meaning of “Guai.”

The icon contains no full product name. “Guai Code” remains the associated brand name, but small desktop-icon sizes require a symbol-only composition.

## Color and Form

- Background: deep coffee-black, approximately `#24130F`.
- Primary G: flame orange, approximately `#FF7043`.
- Anomaly pixel: warm gold, approximately `#FFD166`.
- Container: rounded square with platform-neutral corner geometry.
- Composition: centered, bold, high contrast, and padded enough to survive platform icon masks.
- Finish: clean and modern, with subtle dimensional polish only if it does not reduce small-size clarity.

## Generation Constraints

- Generate a 1024×1024 square master with the built-in ImageGen workflow.
- Keep the mark simple and vector-friendly even though the preview is raster.
- Do not add text, gradients that weaken contrast, mascots, terminal prompts, circuitry, code brackets, watermarks, mockup devices, or scenery.
- Do not imitate another AI or developer-tool brand.
- Preserve a clear silhouette when reduced to 32×32 and 16×16.
- Keep the background within the icon; transparent output is not required for the initial preview.

## Review and Delivery

Inspect the generated master at full size and reduced sizes. The first deliverable is a review preview, not an automatic replacement of existing product icons. After visual approval, save the selected master in the project identity assets and derive platform-specific sizes in a separate implementation step.
